# Проект автоматизации тестирования для учебного сервиса "Доска"
Тесты покрывают следующие ключевые действия пользователя:
- Регистрация нового пользователя
- Авторизация (Login)
- Выход из аккаунта (Logout)
- Создание нового объявления (карточки на доске)

1. Основа для написания автотестов — фреймворк pytest, Selenium WebDriver, Faker (для генерации данных), ChromeDriver / WebDriverManager.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.
